# 원문 자료 안내

이 폴더는 `simple_excluded_areas.csv`(간이과세 배제지역 데이터)를 만들 때 참고한
원본 고시 문서를 그대로 보관합니다. CSV를 나중에 다시 검증하거나, 더 최신 고시가
나왔을 때 비교할 근거로 사용합니다.

## 1. 간이과세배제기준_고시_2024-35호_2024-11-19.hwpx
- 국세청고시 제2024-35호, 2024-11-19 시행
- 출처: 국세청 홈페이지 고시 게시물 첨부파일
  (`https://www.nts.go.kr/comm/nttFileDownload.do?fileKey=c0b6152bb52be5cb280618b865e92e8e`)
- 형식: HWPX (ZIP+XML 컨테이너, 한글 워드프로세서 신형식)
- CSV 적용 여부: 최초 버전(1개 지역만 반영, 이후 v2/v3로 대체됨)

## 2. 간이과세배제기준_고시_2026-01-01시행_전문.hwp
- 2026-01-01 시행 간이과세배제기준 고시 전문
- 출처: 국세청 홈페이지 고시 게시물 첨부파일
  (`https://www.nts.go.kr/comm/nttFileDownload.do?fileKey=a863c05cfd5ac71fa06f1106e737aec2`)
- 형식: HWP (구형 OLE2 바이너리 포맷, pyhwp 라이브러리로 파싱)
- CSV 적용 여부: 두 번째 버전(765행), 이후 v3로 대체됨

## 3. 간이과세배제기준_고시_2026-19호_2026-07-01시행_원문재구성.txt
- **국세청고시 제2026-19호, 2026-07-01 시행** — 2026-09-14 기준 가장 최신·유효한 고시
- 국세청 홈페이지에는 이 버전의 첨부파일이 별도로 존재하지 않아(또는 발견하지 못해),
  국가법령정보센터(law.go.kr)의 행정규칙 뷰어에서 직접 추출했습니다.
- 출처 페이지: `https://www.law.go.kr/LSW/admRulLsInfoP.do?efYd=&admRulId=21174&admRulNm=간이과세배제기준`
- 뷰어는 별표(첨부 표)를 페이지 이미지로 렌더링하며, 이미지 위에 겹쳐지는 글자별
  좌표 텍스트 레이어(XML)를 별도 제공합니다:
  `https://www.law.go.kr/viewer/BYL/ADMRUL/2100000281500/2100000281834/SKIN/166891885/thumbnailxml/{page}.xml`
  (`page` = 0부터 188까지, 총 189페이지. 188은 빈 페이지/404)
- 추출 방법: 각 페이지 XML의 `<text l="" t="" w="" h="">글자</text>` 요소(글자 단위 좌표)를
  y좌표(`t`) 기준으로 허용오차 3.0px로 클러스터링해 같은 줄로 묶고, 그 안에서 x좌표(`l`)
  기준으로 정렬해 줄 단위 텍스트를 재구성했습니다. 재현 가능한 스크립트:
  `backend/_scratch_hwp/fetch_excluded_areas_2026_19.py` (프로젝트 루트 기준 경로,
  현재는 `.gitignore`로 제외된 임시 폴더에 있어 저장소에는 없음 — 필요 시 재생성 가능)
- **주의사항**:
  - 이 파일은 OCR/좌표 기반 텍스트 재구성 결과이므로, 표의 셀 구분이나 일부 특수문자가
    원문과 다르게 뭉쳐 보일 수 있습니다(예: 괄호·쉼표가 붙어서 나오는 등).
  - 법적 효력이 있는 원본은 어디까지나 law.go.kr에 게시된 이미지/공식 고시문이며,
    이 텍스트 파일은 검색·대조용 참고자료입니다.
- CSV 적용 여부: 현재 `simple_excluded_areas.csv`(v3, 447행)의 근거 자료

## 공통 주의사항
- 간이과세 배제지역 고시는 국세청이 매년(또는 수시로) 갱신합니다. 다음에 이 데이터를
  갱신할 때는 국세청 홈페이지(`https://www.nts.go.kr`)에서 최신 고시 번호를 먼저 확인하고,
  없으면 law.go.kr 행정규칙 검색에서 "간이과세배제기준"으로 재검색하세요.
- `backend/app/engine/tax_engine_kr.py`의 `decide_taxpayer_type()`은 `effective_date`가
  주어지지 않으면 오늘 날짜를 기준으로 DB를 조회하므로, 새 고시를 CSV에 추가할 때
  `effective_from` 값만 정확히 넣으면 자동으로 최신 고시가 적용됩니다.
